# Chain Prism · 방법론과 코드 대응

소프트웨어 v0.2.1 기준 · 2026-11-20  
이 표는 공개 코드의 구현 범위를 설명합니다. OCP 원문 전체와의 적합성 인증이나 실제 업무 효과의 평가표가 아닙니다.

## 구현 범위

| 분석·검토 요구 | 코드의 구현 지점 | 현재 범위 | 사람이 확인할 것 |
| --- | --- | --- | --- |
| 범위·시점·자료 성격 고정 | Scope, Input | 범위 버전·시점·설명용/실증 자료 구분 검사 | 범위 설정의 적정성 |
| 입력과 주장 구분 | Input, Assertion | 입력 해시·F/I/H·수치 주장 기록 | 원문 진위·주장 해석 |
| 기술적 실행과 거래구조 구분 | TRow, SRow | 기술 행위·구조·참조·조건부 인계 필드 | 배포 코드·계약·주체의 실제 연결 |
| 근거 계보와 중복 출처 확인 | lineage_roots, evidence_independence | 공유 원천·계보 중첩 보고 | 실질적인 증거 독립성 |
| 분자·분모의 범위 대사 | Reconciliation, calculate_reconciliation | Decimal 계산·포함/제외 항목·결과 저장 | 모집단 완전성·조정 적정성 |
| 불일치 기록 | Discrepancy | 차이 유형·영향·상태·해소 조건 및 버전 관리 | 원인·설명·해소 근거 |
| 판단과 검토 분리 | Judgment, ReviewRequest, Store.review | 작성자 제안·검토 결정·계정 분리·근거 해시 검사 | 충분하고 적합한 증거·전문 판단 |
| 근거 변경 시 재검토 | Store.guardrail, Store.summary | 전이적 의존관계 변경·현재 승인 효력 확인 | 등록되지 않은 외부 변경 |
| 제출 결론 보존 | freeze_conclusion, get_conclusion | 목적·고정본·해시 기록과 재확인 | 제출 적정성·보존 운영 |

## 자동화 범위 밖

- 온체인 수집기·탐색기 연동·문서 파싱·원본 파일 직접 재해싱.
- 전체 QC/FC/RF 라이브러리와 질문 카드 자동 추천.
- 실제 주소의 통제자·법적 권리자 확정.
- 규제 적용성·회계처리·과세권의 자동 판단, 분개·전기.
- 준비자산 실재성·상환능력·운영통제 효과성의 보증.
- 조직 SSO·사용자 수명주기·변조 방지 아카이브·운영 배포.

계정 분리는 실무상 독립성을 자동 보장하지 않으며, 해시 재확인은 DB 관리자에 의한 본문·해시 동시 변조를 막지 않습니다.

## 판본과 해석의 경계

방법론 v1.0, 소프트웨어 v0.2.1, 개별 사례의 기준일과 문서 수정일은 각각 관리합니다. 모듈 번호는 판본별 정의를 확인해야 하며 번호가 같다는 이유만으로 대응시키지 않습니다.

구현 README에는 E3 등급의 복수 해석 허용 여부에 관한 원문 도표·문단 사이의 정합성 검토 사항이 기록되어 있습니다. 이 표로 그 차이가 해소됐다고 주장하지 않습니다.
