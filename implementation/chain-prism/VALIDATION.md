# 검증 기록

## 0.2.1 (2026-11-20)

환경: Python 3.13.18, pydantic 2.13.5. 이 환경에는 FastAPI·Starlette·httpx가 설치되어 있지 않고 네트워크 설치가 막혀 있다.

- `python -m unittest tests.test_core tests.test_v021`: **50개 통과**(기존 코어 31개 + 0.2.1 신규 19개, 마지막 1개는 책 검토 중 나온 DAO 지원금 사례의 E3 채택 오류를 회귀 시험으로 고정한 것).
- `tests/test_api.py`: FastAPI가 없어 **이 환경에서 실행하지 못했다**. 0.2.1에서 API 테스트 3개(토큰 기반 작성자 기록과 본문 위조 거부, 자기 판단 검토 차단, 결론 스냅샷 엔드포인트)를 추가했지만 실행 확인 전이다. FastAPI가 설치된 환경에서 `python -m unittest discover -v`로 확인해야 한다.
- 전체 출력은 test-results.txt(API 모듈 import 오류 1건 포함), 설명용 계산 결과는 demo-result.json.

0.2.1 신규 테스트가 확인하는 것:
- 작성자 없는 판단 등록 거부, 작성자의 자기 판단 검토(승인·수정 요청 모두) 거부, 작성자 기록의 노출
- 작성자 제안과 다른 검토 결정은 해소 근거 없이 거부, 등급과 맞지 않는 제안 거부, 도표 C-1 등급표
- 작성자 열이 없는 이전 DB 열기와 작성자 미상 판단의 검토 차단
- 미해소 차이는 확정만 차단, 판단 등록 시 차이 숨김 거부, 판단 뒤 발견된 차이로 재검토·전체 차단, 차이 상태 변경 시 재검토
- 차이 기록 자체의 규칙(해소 조건, 설명 근거, 미해결 유형, 대상 유형)
- 시점 차이 사유 필수, 설명된 fact_timing 차이 전까지 확정 차단, 시점이 다른 입력의 대사 투입 거부
- 결론 스냅샷의 보존(근거 변경 뒤에도 고정본 유지), 미완 표시, 분석자 고정 거부, 본문 변조 탐지
